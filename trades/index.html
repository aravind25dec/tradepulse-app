Connect Robinhood via MCP

In a terminal:
npm install -g @anthropic-ai/claude-code
Then sign in once:

Register Robinhood MCP
In a terminal:
claude mcp add robinhood-trading --transport http https://agent.robinhood.com/mcp/trading
Auth happens in your browser via Claude Pro — no credentials stored locally.
